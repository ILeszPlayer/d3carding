### Detail Alur Singkat (bisa di notes atau slide terpisah)

**Free Play:**
```
User buka web → Klik "Connect" → Pilih COM port Arduino
  ↓
Klik tombol "Sol" di layar
  ↓
Browser kirim "SOL1_ON\n" via Web Serial API (115200 baud)
  ↓
Arduino terima → Parse command → Aktifkan motor Sol Rendah
  ↓
Motor push (70ms) → Tabung kena → Angklung berbunyi
```

**Rhythm Mode:**
```
Game dimulai → Chart lagu (JSON) dimuat
  ↓
Nota berjatuhan di 14 lajur
  ↓
Klik tepat waktu → Timing detection:
  Perfect (<50ms)  → 300 poin
  Great (50-100ms) → 200 poin
  Good (100-150ms)→ 100 poin
  Miss (>150ms)   → 0 poin
  ↓
Skor × Combo → Tampil di layar
```

**Learning Mode (6 Lesson):**
```
Lesson 1: Pengenalan Nama Nada
Lesson 2: Pengenalan Bunyi Nada (dengar + tebak)
Lesson 3: Sequence 2-3 Nada
Lesson 4: Tangga Nada
Lesson 5: Bagian Lagu
Lesson 6: Sight Reading
  ↓
Instruksi + highlight nada → User tekan
Feedback: Hijau ✅ / Merah ❌
Progress bar → Bintang ⭐⭐⭐
```

## 💡 Tips Umum Canva

1. **Gunakan template yang sama** untuk semua slide biar konsisten
2. **Copy slide** yang sudah jadi daripada buat baru tiap kali
3. **Grouping:** Group elemen-elemen yang jadi satu kesatuan (biar gampang dipindah)
4. **Shortcut:** 
   - `Ctrl+D` = duplikat elemen
   - `Ctrl+G` = group
   - `Ctrl+Shift+L/R/C` = align left/right/center
5. **Animasi (opsional):** Tambahkan animasi "Fade in" atau "Slide up" untuk transisi yang mulus
6. **Background konsisten:** Set background yang sama di semua slide (warna atau gradient)
7. **Gunakan Pages Panel** untuk lihat semua slide sekaligus
